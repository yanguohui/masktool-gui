# 用户词库模板（UTF-8 编码，可用记事本 / 文本编辑器编辑）
#
# 使用说明：
#   1. 以 # 或 // 开头的行是注释，导入时会被自动忽略，可放心写说明。
#   2. 每行可带「类别前缀」，前缀后接中文冒号“：”或英文冒号“:”，再写词。
#      支持的类别前缀：公司名 / 人名 / 项目名 / 机构 / 单位 / 地名 / 金额 / 自定义
#      （也可写英文：company / person / project / government / location / amount / custom）
#   3. 没有前缀的行，会导入到界面下拉框「当前选中的类别」。
#   4. 多个词可用 逗号、顿号、分号 分隔，也可以一行只写一个词。
#   5. 词库匹配是「精确包含」，建议写完整名称，例如“北京云端科技有限公司”而非“云端”。
#   6. 把下面的示例换成你自己的真实信息，保存为 .txt 后，在程序里点「导入TXT」即可。
#
# ---- 以下为示例，请替换 ----

公司名：北京云端科技有限公司
公司名：上海恒通实业集团有限公司
人名：张伟
人名：李华
项目名：智慧城市大脑三期工程
机构 / 单位：国家信息安全技术研究中心
地名：海淀区
金额：1250万
自定义：某某专项工作组
