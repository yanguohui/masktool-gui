# 本地文档脱敏工具（GUI）

为 [ZagooYWX/mask-tool](https://github.com/ZagooYWX/mask-tool) 提供的图形界面封装。

所有文件处理均在本地完成，**不会上传任何内容到云端**。

## 下载即用

### macOS（本机构建版本）

1. 在 Finder 中双击 `本地文档脱敏工具`（单文件可执行程序，约 110 MB）。
2. 若系统提示“无法打开”，请在 Finder 中右键 →“打开”一次即可。
3. 程序已内置 `mask-tool`、jieba 词库与默认配置，**无需安装 Python 或任何依赖**。

### Windows

PyInstaller 不能跨平台编译，Windows `.exe` 需要在 Windows 上另行打包（见下文的“自行打包”）。

## 功能

- 批量选择 `.docx` / `.pdf` / `.xlsx` / `.pptx`。
- 选择 `strict` / `smart` / `aggressive` 三种脱敏模式，`smart` 为默认。
- **检测灵敏度（仅 smart 模式可见/生效）**：可自主调节智能识别的“宽严”，
  鼠标悬停每个选项会显示释义。默认 `中（推荐）` 已大幅降低对普通词语的误伤。
  （`strict` 只用用户词库、`aggressive` 已是最高召回，故不显示此选项。）
- **用户词库**：界面可直接添加公司名、人名、项目名等自定义敏感词；支持从 TXT 批量导入，并随设置自动保存。
- **白名单（`whitelist.txt`）**：在程序根目录放置 `whitelist.txt`，逐行列出"绝不脱敏"的业务术语（如 `二次开发`、`许可`、`卖方`、`买方`、`工程`）。脱敏前会先读取并保护，无论来自词库、正则还是 NER，都原样保留。
- **置信度下限**：界面「识别引擎」区可设置全局置信度下限（默认 0.8）。低于该值的识别结果只在报告里提示、不改动正文，进一步减少把"把握不大"的词误脱敏。
- **可插拔 NER 后端**：界面「识别引擎」区可切换 `自动 / spaCy / jieba` 三档识别引擎。**已内嵌 spaCy 中文模型 `zh_core_web_md`**，`自动`/`spaCy` 开箱即用，无需用户安装；亦支持指定通信工程等领域微调模型路径。
- 输出目录默认与原文件相同，文件名自动追加 `_脱敏` 后缀。
- 实时进度条、逐文件状态、处理完成后弹窗汇总。
- 支持导出映射表，用于后续还原脱敏内容。
- 支持双击结果行直接打开对应输出文件。

## 用户词库（strict 模式的核心）

| 模式 | 自动脱敏规则 |
|------|------|
| `strict` | 主要脱敏**词库匹配**（置信度 0.95）；金额、手机号等高置信度正则项也会被脱敏。 |
| `smart` | 在词库基础上，叠加 jieba NER + 正则，适合日常办公。 |
| `aggressive` | 降低阈值，最大化召回，可能误伤普通词。 |

## 检测灵敏度（仅 smart 模式）

智能模式（`smart`）会用 jieba NER 自动识别人名、机构、地名等，并叠加一组**高置信正则**
直接命中：手机号、身份证、邮箱、IP、MAC、日期，以及**中文大写金额**（如"陆拾万元"）、
**阿拉伯金额**（如"1,200,000元"）和**项目/工程名**。
这些高置信正则**无论灵敏度如何都照常脱敏**，因此预算、合同金额、客户机构名、项目名
通常都能被自动覆盖。

> **项目/工程名识别已收紧**：必须是「以边界字符起始、内部含实体指示词（系统/平台/扩容/
> 软件…）、且不以"根据/卖方/确保/本/该…"等动词或指代词开头」的专有名词短语，因此
> 不会再像旧版那样把整句「卖方应在本项目」「根据项目」「参加过的重要项目及在该项目」
> 整段吞掉。

> **结构化字段识别（高召回、不误伤）**：技术规范书 / 合同里常以「标签：值」形式标注敏感
> 信息（如 `项目名称：网络威胁感知子系统`、`客户名称：中国移动通信集团有限公司`、
> `建设单位：中电信数智科技有限公司`、`项目地点：北京市海淀区上地软件园`、
> `中标人 / 甲方 / 乙方 / 供货商 / 联系人` 等）。这类字段无论灵敏度档位如何都**直接命中
> 标签后的值并脱敏**——既解决了"陌生机构名 / 不以项目·工程结尾的系统名"被 NER/词库漏检
> 的问题，又因为属于高置信正则、不受 NER 误报抑制影响，不会误伤"根据/买卖双方"等普通词。

jieba NER 在技术规范书 / 合同里会把大量普通词语误标为实体（如"网络安全""买卖双方"
"根据""日志""深度"），且这些误报与真实机构名置信度高度重叠、单靠阈值无法区分。
为此工具在策略层做了一道**与灵敏度档位无关的 NER 误报抑制（结构准入制）**：

- **不依赖任何实体词库 / 映射表**：抑制不是"列黑名单"，而是检查候选是否满足对应
  实体类型的**中文构词规则**（见下文「自主识别」）。因此对从未见过的普通词同样有效——
  无论这个词多常见或多冷门，只要它不满足机构 / 人名 / 地名的构词形态，就原样保留。
- **类型校验（构词法）**：人名仅接受「高频姓氏 + 名」形态的 2~4 字字符串，且整体不是
  透明普通词（如"明白""应予以"虽以罕见姓氏起头，但属普通动词，被抑制）；地名仅接受
  以省/市/区/县/路/街/号…等地名后缀结尾的词（裸"中国/北京"等过于泛化、非敏感，不脱敏）；
- **单字实体**：长度 ≤1 的 NER 结果几乎都是噪声，强制不脱敏。

jieba NER 的置信度上限仅 0.85，且"人名/机构/地名"的可靠性差异很大：机构名最可靠、
人名次之、地名误报极多。因此「检测灵敏度」**按实体类型分别设阈值**（机构最宽松、地名最严），
而不是一刀切：

| 档位 | 行为 | 适用场景 |
|------|------|----------|
| `高（激进召回）` | NER 低置信项也参与脱敏，误伤最多 | 宁可错杀、事后人工复核（仍受上述误报抑制约束） |
| `中（推荐）` | 正则/金额/项目名照常脱敏；机构名、人名（含客户/联系人姓名）基本都能命中；仅压制低置信地名误报 | 日常办公默认 |
| `低（保守精准）` | 只脱敏较高置信的 NER 项，几乎不误伤 | 对误报敏感、短人名可交词库 |
| `极低（审慎）` | 几乎只保留用户词库匹配项 | 误报零容忍、宁可漏掉 |

> 即便选「高（激进召回）」，上述 NER 误报抑制层也会生效，因此"根据""买卖双方"
> "网络安全"等无关信息不会被脱敏；被脱敏的仍主要是真实的人名 / 机构 / 联系方式 / 金额 /
> 日期 / 项目名。

> 灵敏度仅对 `smart` 模式可见并生效；切换为 `strict`（只用用户词库）或 `aggressive`
> （最高召回）时该选项自动隐藏。把确切的公司全称、客户姓名、项目名称等维护到
> 「用户词库」中，可让所有模式（尤其 `strict`）的脱敏更稳定、可控。
>
> 每个选项在界面上都有**悬浮释义**（鼠标悬停即显示），也可在下方常驻说明中查看。

## 自主识别（不依赖映射库）

工具的智能识别**不依赖任何机构名 / 客户名 / 项目名实体库或映射表**——它不会"记住"
已知的公司或项目，而是基于**中文命名构词法**与**汉语词性（语法）规律**自主判断，因此
能命中**任意陌生**的机构、项目、人名、地址，同时不会误伤普通词（"根据""买卖双方"
"网络安全"等）。

- **组织机构名**：以组织形式后缀（有限公司 / 集团 / 局 / 厅 / 中心 / 协会 / 大学 …）
  收尾，且内部含合理构词（"发展和改革委员会""行政执法监督局"中的连词、动词合法）；
  起点由词性定界——介词、代词、副词、助词绝不在专名内部，据此剥离左侧谓语
  （"运营数据**接入**昆山市大数据管理局"→ 正确断开）。
- **项目 / 工程名**：以项目类中心词（项目 / 工程 / 标段 / 课题 / 专项 …）收尾，且内部
  含实体指示语素（系统 / 平台 / 建设 / 扩容 / 改造 …），因此"重要项目""该工程"等泛指
  不会命中，而"全线通信传输网络扩容项目"会被完整识别。
- **人名**：标签语境（联系人 / 负责人 / 甲方 …）下，值按构词校验（排除机构 / 地名 /
  抽象概念）；自由文本中的人名借助 NER 并以「高频姓氏 + 名」形态二次过滤，避免
  "明白""应予以"等普通词被误判。
- **地址**：行政区划链（省 / 市 / 区 / 县）+ 街路号 / 园区 / 大厦，贪婪取最长。
- **词性定界（关键创新）**：中文无词间空格，纯正则无法定位专名左边界。工具改用
  jieba 词性标注确定边界——硬断词（介词 / 代词 / 副词 / 助词）之后、软断词（多字谓语
  动词）之后逐级回退，取首个构词成立的片段；并对"委托国家…检验中心"这类
  "谓语动词 + 专名"结构做机构起头清洗。整套定界**不含任何实体词，纯靠语法**。

> 正因为不依赖词库，本工具对**训练 / 样本外**的陌生实体同样有效：换一份全新的
> 标书或合同，照样能正确识别其中的机构与项目，无需事先登记。

**建议**：把真实的公司全称、客户姓名、项目名称等维护到"用户词库"中，这样：
- 切换 `strict` 模式时仍有稳定、可控的脱敏效果；
- 所有模式下的脱敏结果都更精准；
- 词库随设置自动保存，重启程序后仍在。

> 词库匹配是**精确包含**（不是模糊匹配），因此建议填入完整名称，例如"北京云端科技有限公司"而不是"云端"。

## 白名单与识别引擎（进一步减少误脱敏）

上一节介绍的策略层误报抑制已能挡掉绝大多数"根据 / 买卖双方 / 网络安全"等普通词。
但某些**业务术语本身就是你绝不想被替换的**（如 `二次开发`、`许可`、`卖方`、`买方`、`工程`），
而它们又可能偶然被 NER 标成实体。为此工具提供两层兜底：

### 1. 白名单 `whitelist.txt`

**推荐方式**：点击软件界面**右上角的「白名单…」按钮**即可打开可视化编辑器，
直接增删词条并保存，无需手动编辑文件。保存后立即生效（下次脱敏自动读取）。

如需手动维护，也可在项目**根目录**新建 `whitelist.txt`（UTF-8 编码），逐行写入"绝不脱敏"的词，
例如：

```text
# 业务术语，绝不脱敏
二次开发
许可
卖方
买方
工程
```

- 以 `#` 开头的行是注释；
- 每行一个词，支持前缀修饰（同用户词库导入规则，见下文「TXT 批量导入格式」）；
- **优先级最高**：白名单中的词无论来自词库、正则还是 NER，一律原样保留；
- 改完保存即可，**下次批量处理自动生效**，无需重启程序。

### 2. 全局置信度下限

界面「识别引擎」区的**置信度下限**滑条（0~1，默认 0.8）控制：

- 识别结果的置信度 ≥ 下限 → 按正常策略决定是否脱敏；
- 识别结果的置信度 < 下限 → 只在检测报告里提示（HINT），**不改动正文**。

调高下限（如 0.9）可让"把握不大"的识别全部失效、几乎零误伤；调低（如 0.0）则回到
不受置信度约束的原始行为。该值已写入配置文件 `min_confidence`，每次批量处理整批生效。

### 3. 可插拔 NER 后端（含 spaCy）

界面「识别引擎」区提供**识别引擎**下拉框，三档可选：

| 选项 | 含义 |
|------|------|
| `自动（auto，默认）` | 内置了 spaCy 中文模型就用 spaCy，否则自动回退到 jieba。 |
| `spaCy` | 强制使用 spaCy 命名实体识别（程序已内嵌 `zh_core_web_md`）。 |
| `jieba` | 强制使用 mask-tool 内置的 jieba NER。 |

- **已内嵌 spaCy 模型**：打包后的单文件程序**已经内置 `zh_core_web_md`**，
  `自动` / `spaCy` 模式开箱即用，无需用户另行安装 spaCy 或下载模型。
- **spaCy 模型路径**：留空时使用内嵌的 `zh_core_web_md`；若你有针对通信工程等领域
  **微调的模型**，点「浏览」选中其目录（或填绝对路径）即可覆盖默认模型，
  例如 `models/telecom_ner`。
- 切换引擎 / 模型 / 置信度后，会**即时生效并应用于整批文件**，无需重启。

> **领域微调模型怎么来？** 程序已支持自动发现 `models/` 下的领域模型，但模型文件需
> 你自备语料训练。仓库附 `tools/train_spacy_ner.py` 训练脚本：准备一份含标注实体的
> 语料（每行一条 JSON，含 `text` 与 `entities`），运行即可在 `models/` 下产出
> spaCy 模型目录，再在 GUI 里通过「spaCy 模型路径」指向它。详见该脚本头部注释。

### TXT 批量导入格式

点击「导入TXT」可一次性导入大量词。文件需为 **UTF-8 编码**的纯文本，解析规则：

- 以 `#` 或 `//` 开头的行是**注释**，导入时忽略（模板里可写说明）；
- 每行可带**类别前缀**，前缀后接中文冒号 `：` 或英文冒号 `:`，再写词；
  - 支持前缀：`公司名 / 人名 / 项目名 / 机构 / 单位 / 地名 / 金额 / 自定义`
  - 也支持英文：`company / person / project / government / location / amount / custom`
- **没有前缀**的行，会导入到界面下拉框「当前选中的类别」；
- 同一行可用 逗号 `、` 顿号 `、` 分号 `;` 分隔多个词，也可以一行一个词；
- 空行自动忽略。

**模板示例**（`词库模板.txt`）：

```text
# 这是注释，导入时会被忽略
公司名：北京云端科技有限公司
公司名：上海恒通实业集团有限公司
人名：张伟
人名：李华
项目名：智慧城市大脑三期工程
机构 / 单位：国家信息安全技术研究中心
地名：海淀区
金额：1250万
自定义：某某专项工作组

# 没有前缀的行，归入下拉框当前选中的类别
某客户名称A
某客户名称B
```

> 项目根目录已附 `词库模板.txt`，直接复制改名、替换示例内容后即可导入。
> strict 模式下，词库是脱敏的主力来源，建议把真实公司全称、客户姓名、项目名称都维护进去。

## 关于 PDF

当前 mask-tool 对 PDF 的处理策略为**仅生成检测报告（JSON）**，不会回写新的 PDF 文件。因此选择 PDF 时，输出的是 `_脱敏_检测报告.json`，GUI 会明确标注“PDF 仅输出检测报告”。

## 脱敏效果说明

- 默认 `smart` 模式启用了轻量 jieba NER，并叠加**基于构词法的自主识别**（见上），可自动识别并替换**人名、机构名、项目名、地名、金额、手机号、邮箱、身份证号、日期**等敏感信息。
- 对于**公司名、项目名**，智能识别不再依赖 jieba 是否把长名称切分为一个完整实体：基于组织形式后缀 + 词性定界，能完整命中长机构名（如"中铁建电气化局集团第三工程有限公司"）、弱后缀机构（如"昆山市大数据管理局"）与项目名（如"城市轨道交通智慧运维管控平台"）。
- 所有替换都是可逆的，映射表会随结果一并输出（`xxx_脱敏_映射表.json`），可用于还原。
- 如需更高的召回率，可在 GUI 中选择 `aggressive` 模式，或把「检测灵敏度」调高；
  如需更保守，可把「检测灵敏度」调低，或切换 `strict` 模式。
- 旧版通过修改 `assets/mask_tool_config/default.yaml` 的 `thresholds.auto_mask`
  来调节的方式已不建议，请使用 GUI 中的「检测灵敏度」开关（更直观、可悬浮释义）。

## 自行打包

### macOS

```bash
git clone <本仓库地址>
cd masktool-gui
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python3 -m PyInstaller --noconfirm masktool_gui.spec
```

`requirements.txt` 已包含 `pyinstaller` 与 `mask-tool`（从 GitHub 安装），
无需再手动安装脱敏引擎。打包完成后会在 `dist/` 下生成单文件可执行程序
`本地文档脱敏工具`。

### Windows

```bat
git clone <本仓库地址>
cd masktool-gui
build.bat
```

打包完成后会在 `dist/` 下生成 `本地文档脱敏工具.exe`。

- 打包/运行本 GUI：标准库 `tkinter` + `PyInstaller`。
- 实际脱敏能力已内嵌在打包后的单文件程序中；开发调试时才需要单独安装 [ZagooYWX/mask-tool](https://github.com/ZagooYWX/mask-tool)：

```bash
git clone https://github.com/ZagooYWX/mask-tool.git
cd mask-tool
pip install -e .
```

```bash
pip install spacy
python -m spacy download zh_core_web_md   # 内嵌的同款中文模型
```

> 打包时在 `masktool_gui.spec` 里通过 `collect_all("spacy")` 与
> `collect_all("zh_core_web_md")` 将 spaCy 及其中文模型整体卷进 exe，
> 因此最终用户无需单独安装；体积相应增大（约 +150~200 MB），属预期内。

## 目录结构

```
masktool-gui/
├── app/
│   ├── __init__.py
│   ├── engine.py      # mask-tool 定位与调用封装（含白名单/置信度/NER 后端补丁）
│   ├── settings.py    # 配置持久化（含 min_confidence / ner_backend / spacy_model）
│   ├── ner_backend.py # 可插拔 NER 后端（auto/spaCy/jieba 工厂与状态查询）
│   └── ui.py          # Tkinter 图形界面（含「识别引擎」开关区）
├── main.py            # 程序入口
├── whitelist.txt      # 白名单：逐行列出绝不脱敏的业务术语
├── 词库模板.txt        # 用户词库 TXT 导入模板（含格式说明）
├── tools/
│   ├── make_icon.py       # 生成 assets/app.ico
│   └── train_spacy_ner.py # 领域 spaCy NER 模型微调训练脚本
├── models/            # （可选）存放领域微调的 spaCy 模型，GUI 可自动发现
├── assets/
│   ├── app.ico
│   ├── mask_tool_config/   # 内嵌的 mask-tool 默认词库与阈值配置
│   │   ├── default.yaml
│   │   ├── sample_lexicon.yaml
│   │   └── whitelist.yaml
│   └── version.txt
├── requirements.txt
├── masktool_gui.spec  # PyInstaller 配置
├── build.bat          # Windows 一键打包
└── .github/workflows/build-windows.yml
```
